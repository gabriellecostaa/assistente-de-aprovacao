# 🐍 Assistente de Aprovação

Um programa desenvolvido em Python para calcular a média de alunos e informar sua situação acadêmica.

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em programação e tem como objetivo praticar lógica de programação, funções, estruturas condicionais, validação de dados e estruturas de repetição.

## ✨ Funcionalidades

- 👤 Cadastro do nome do aluno
- 📝 Registro de 4 notas
- 🧮 Cálculo automático da média
- ✅ Identificação de aluno aprovado
- ⚠️ Identificação de aluno em recuperação
- ❌ Identificação de aluno reprovado
- 🛡️ Validação das notas entre 0 e 10
- 🔢 Tratamento de entradas inválidas
- 🔄 Menu interativo
- 👥 Possibilidade de cadastrar vários alunos
- 🚪 Opção para encerrar o programa

## 🛠️ Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`)
- Funções (`def`)
- Tratamento de exceções (`try` / `except`)
- Entrada e saída de dados
